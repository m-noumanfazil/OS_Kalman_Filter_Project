# Assessment evidence map

This map connects the five rubric criteria to reviewable project evidence; it does not assert a mark or full compliance. The assignment's 15-call wording lists 15 Linux interfaces and only 12 Windows APIs. Instructor clarification remains outstanding. See the [current report](../report/final_report.md) for the full discussion and the [Phase 0 inventory](phase-0-baseline.md) for historical per-category source and evidence links.

Individual call timings and resource values use platform-specific accounting and scopes; shared pages cannot be summed into unique physical memory. A complete reproducible comparison requires equivalent workloads, comparable environments, retained raw samples, and explicit timing boundaries. The project records observed slowdowns rather than claiming the rubric's speedup objective was achieved.
