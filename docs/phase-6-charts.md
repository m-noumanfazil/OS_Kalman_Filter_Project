# Phase 6 chart provenance

Generate the figures from the repository root with an already installed Python and matplotlib:

```sh
python common/generate_phase6_charts.py
```

The script uses the noninteractive Agg backend and defaults to `results/charts/phase6`. Pass `--output-dir <directory>` to generate copies elsewhere. It reads the saved data directly, validates the selected medians or means against their raw values, and overwrites its two named output images. It leaves the historical 2D charts in `results/charts` untouched. The script and figures were run with Python 3.12.10 and matplotlib 3.11.0; plotting library versions and fonts may alter rendering.

- `windows_ekf3d_scaling.png` reads [Phase 4 samples, summary, and manifest](../results/phase4/windows-clean-f6435cf/). Each point represents a native 3D EKF end-to-end invocation on one Windows machine, with 1,800 observations, three tracks, and batch size 32 or 512. Lines connect medians of three timed runs; individual timings are visible. The figure includes process startup, file I/O, logging and synchronization; it is not a cross-platform comparison.
- `imm_ekf_multiseed_accuracy.png` reads the [Phase 5 multi-seed manifest](../results/phase5/multiseed-fe04715/manifest.json). Each dot represents the 3D position vector RMSE in one seed; a line connects the EKF and IMM for that same seed. Short horizontal marks are arithmetic means of per-seed RMSE, not pooled RMSE. The same synthetic trajectories, observation times and gaps are used across seeds, and the models have different process-noise parameters. The figure does not establish general or real-world superiority.

The [Phase 5 seed-42 model probability plot](../results/phase5/multiseed-fe04715/seed42-probabilities.svg) is generated by `common/compare_imm3d.py` from sequential output. See [phase-5-imm.md](phase-5-imm.md) for its build and comparison commands. Model probabilities are diagnostic weights, not proven motion-classification labels.
